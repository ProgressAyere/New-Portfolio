# Progress Ayere - Frontend Developer Portfolio

A modern, high-performance portfolio website showcasing interactive web experiences, Web3 builds, and motion design systems. Built with Next.js, Framer Motion, and GSAP for cinematic animations and smooth user interactions.

![Portfolio Preview](./public/profile-image.png)

## 🚀 Features

- **Animated Splash Screen** - Eye-catching entry experience with ProGem NFT character
- **Interactive Hero Section** - Dynamic word-by-word animations with video showcase
- **Project Showcase** - 3D tilt effects, video crossfades, and expandable case studies
- **Infinite Reel Strip** - GSAP-powered horizontal scroll with pause-on-hover
- **Services Section** - Animated conic-gradient borders with video device frames
- **Testimonials Carousel** - Draggable testimonials with smooth transitions
- **Custom Cursor** - Spring physics-based cursor with hover interactions
- **Responsive Design** - Mobile-first approach with seamless desktop scaling
- **Performance Optimized** - Fast loading times with optimized assets

## 🛠️ Tech Stack

- **Framework:** Next.js 15.1.3
- **Styling:** Tailwind CSS 3.4.1
- **Animations:** 
  - Framer Motion 11.15.0
  - GSAP 3.12.5 with ScrollTrigger
- **Icons:** 
  - React Icons 5.4.0
  - Lucide React 0.468.0
  - Font Awesome 6.7.2
- **Language:** JavaScript (ES6+)

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/portfolio.git
cd portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser
